# KittenFish NNUE

The NNUE trainer, dataset converters, experiments and tests have moved to
[kittenfishtraining/v1](https://github.com/crazykitten43/kittenfishtraining/tree/main/v1).

The inference-only NNUE evaluator, alpha-beta search and UCI engine are in
[kittenfishv1](https://github.com/crazykitten43/kittenfishv1).

The existing [lichess-500k-v1 trained-model release](https://github.com/crazykitten43/kittenfishnnue/releases/tag/lichess-500k-v1)
remains here so kittenfishv1's verified model download continues working.
Original source files remain available in Git history.
